# Threat model

## 2026-10-11 · Đăng nhập cho app, truy cập qua LAN và Tailscale
Luồng:
- Trình duyệt (điện thoại, laptop) → HTTP tới TUF. Hiện nay vào thẳng `192.168.1.10:8000` trong LAN; sắp tới vào thêm qua Tailscale (IP tailnet `100.64.0.1` hoặc `tailscale serve` HTTPS, KHÔNG dùng Funnel).
- FastAPI (`app.py`): 37 route `/api/*` và static mount `/` (`app.py:5754`), hiện không kiểm ai gọi.
- Tài sản: tài liệu, bản dịch, trò chuyện, ghi chú trong `data/`; key API trong `data/keys.json`; hạn mức LLM (OpenRouter, proxy ChatGPT); hệ thống file của TUF.
- Mới: trang đăng nhập → `POST /api/login` → cookie phiên → một middleware kiểm mọi request trước khi tới route hay static.

Rủi ro còn lại (báo người dùng 2026-10-11, chưa xử lý):
- Cookie gắn theo tên máy, không theo cổng: dịch vụ khác trên cùng `<máy>.<tailnet>.ts.net` (cổng 443, qdh qua Funnel) cũng nhận cookie `vp_session` khi trình duyệt của chủ máy mở nó. Request từ trang đó sang app bị chặn bởi kiểm Origin đủ host:cổng (TM-4); còn lại là server qdh tự đọc được cookie trong request — xử lý ở việc riêng "Siết hai dịch vụ đang mở trên TUF".

## 2026-10-15 · Tự kiểm giá model (OpenRouter `/models`)
Luồng:
- Lúc khởi động, một thread nền gọi `GET https://openrouter.ai/api/v1/models` (công khai, không key, host cố định trong code). `POST /api/models` (người dùng đã đăng nhập bấm ↻) gọi `<base_url>/models` của server người dùng chọn, như trước.
- Server đọc `pricing.prompt`, `pricing.completion` (dữ liệu bên ngoài, không tin được), lưu cùng thời điểm tải vào `data/model_meta.json`.
- Giao diện hỏi `POST /api/model_prices` với các cặp (base_url, model) đang chọn cho dịch, trò chuyện, thuật ngữ, xem ảnh (và OCR, căn vệt tô), hiện dải cảnh báo khi giá khác 0; bấm "đã biết" lưu khoá model+giá trong localStorage.
- Tài sản: tiền OpenRouter của người dùng (model đổi giá thì request vẫn chạy và bị tính tiền), key API, khả năng khởi động của app.
